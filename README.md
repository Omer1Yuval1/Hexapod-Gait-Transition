# Hexapod-Gait-Transition

# Installation
- Create a Python environment
- Install dependencies `pip install -r requirements.txt`

# Training
- Activate Python Environment.
- Run `python main.py mole_cricket` in the terminal.
- The view training progress using Tensorboard in Visual Studio Code
    * In the search bar, select "Show and Run Commands"
    * Select "Python: Launch Tensorboard"
    * Select "Select another folder"
    * Select the Tensorboard directory of the trained model. For example, for the mole cricket model: `./resources/results/mole_cricket/tensorboard_log`

# Evaluation
- Check `./resources/results/mole_cricket/locomotion/`
